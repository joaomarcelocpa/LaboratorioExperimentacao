Métricas DORA em — repositórios open-source

Uma aba por pergunta de pesquisa: a hipótese, o que os dados mostram e a conclusão. A cor do ponto em cada aba indica se a hipótese se confirmou, se confirmou em parte ou se foi refutada.

Página estática gerada por python -m analise.painel a partir dos CSVs do repositório. As hipóteses estão em docs/hipoteses.md. Os vereditos e as conclusões são uma leitura dos dados, em rascunho para a seção de Resultados e Discussão do artigo.
