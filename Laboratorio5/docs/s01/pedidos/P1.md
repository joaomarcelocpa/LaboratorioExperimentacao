# P1 — Aviso de vencimento de tarefa

**Tipo:** Cabe na arquitetura
**Ordem no piloto:** 1

---

[CONTEXTO] O projeto está no diretório atual.

[NECESSIDADE] Quem criou uma tarefa precisa ser avisado quando ela vencer sem ter sido concluída,
para não perder prazos.

[COMPORTAMENTO PARA O USUÁRIO] Existe uma tela de Avisos acessível pela aplicação
(identificador de interface: `data-testid="lista-avisos"`). Quando uma tarefa não concluída
ultrapassa o seu vencimento, um aviso com o título da tarefa aparece nessa tela.
Tarefas já concluídas não geram aviso. Cada tarefa gera no máximo um aviso.

[CRITÉRIOS DE ACEITAÇÃO]
- Uma tarefa criada com vencimento 5 segundos no futuro gera um aviso visível na tela de Avisos
  em até 30 segundos após o vencimento.
- Uma tarefa concluída antes do seu vencimento não gera nenhum aviso.
- Cada tarefa gera no máximo um aviso, mesmo que o sistema seja consultado repetidamente.

[SAÍDA] Implemente a mudança no próprio projeto. O resultado será verificado por testes
automatizados de comportamento.
