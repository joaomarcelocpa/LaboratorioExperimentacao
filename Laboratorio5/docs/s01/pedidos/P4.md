# P4 — Importação de tarefas via CSV

**Tipo:** Cabe na arquitetura
**Ordem no piloto:** 4

---

[CONTEXTO] O projeto está no diretório atual.

[NECESSIDADE] Clientes precisam cadastrar muitas tarefas de uma vez a partir de uma planilha,
sem digitar uma a uma. O arquivo tem as colunas título, responsável e vencimento.

[COMPORTAMENTO PARA O USUÁRIO] Na tela de tarefas, o usuário escolhe um arquivo CSV
(campo com `data-testid="importar-csv"`) e confirma a importação. Durante o processamento
a tela continua respondendo normalmente. Ao final, uma área na tela
(`data-testid="resultado-importacao"`) mostra quantas tarefas foram importadas com sucesso e
lista as linhas com erro, com o número de cada linha.

[CRITÉRIOS DE ACEITAÇÃO]
- Um CSV com 20.000 linhas, das quais 50 são inválidas (título ausente ou vencimento fora do
  formato), resulta em 19.950 tarefas importadas e exatamente 50 erros listados com o número
  da linha correspondente.
- A tela continua respondendo durante o processamento: o usuário consegue navegar ou consultar
  outras tarefas enquanto a importação ocorre.
- Linhas inválidas não geram tarefas parciais; as válidas são salvas integralmente.

[SAÍDA] Implemente a mudança no próprio projeto. O resultado será verificado por testes
automatizados de comportamento.
