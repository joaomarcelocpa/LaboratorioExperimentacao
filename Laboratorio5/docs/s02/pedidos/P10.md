# P10 — Troca do banco de dados (sonda final)

**Tipo:** Tensiona a arquitetura
**Ordem na coleta completa:** definida no protocolo congelado (último pedido)

---

[CONTEXTO] O projeto está no diretório atual.

[NECESSIDADE] O sistema usa PostgreSQL. A equipe precisa verificar se a camada de
persistência está suficientemente isolada para suportar uma troca de banco de dados sem
reescrever as regras de negócio. Este pedido é uma sonda: se a arquitetura produzida ao longo
dos passos anteriores isola bem a persistência, a troca será localizada; se não isola, a
regressão aparecerá nos testes.

[COMPORTAMENTO PARA O USUÁRIO] O sistema deve funcionar exatamente como antes, mas usando
H2 (banco em memória) no lugar do PostgreSQL. Todas as operações de tarefas continuam
disponíveis. Nenhum comportamento visível ao usuário muda.

[CRITÉRIOS DE ACEITAÇÃO]
- Iniciar a aplicação com H2 (perfil `h2`) funciona sem erro.
- Criar, listar, atualizar, concluir e excluir uma tarefa com H2 retornam os mesmos status
  HTTP e comportamentos que com PostgreSQL.
- Nenhum teste da suíte falha ao rodar contra H2 no perfil `h2`.
- O perfil padrão (PostgreSQL) continua funcionando.

[SAÍDA] Implemente a mudança no próprio projeto. O resultado será verificado por testes
automatizados de comportamento.

---

## Mínimo observável

| Elemento | Identificador |
|---|---|
| Perfil de configuração H2 | `spring.profiles.active=h2` (ou equivalente) |
| Comportamento esperado | idêntico ao PostgreSQL para todos os critérios de P1 a P9 |

> Este pedido não exige nova interface visual nem novos endpoints: o mínimo observável é a
> ausência de regressão ao trocar o banco.

## Rastreio critério ↔ teste (caixa-preta)

| Perfil padrão PostgreSQL não regrediu | _(verificado pela suíte no perfil padrão)_ |
